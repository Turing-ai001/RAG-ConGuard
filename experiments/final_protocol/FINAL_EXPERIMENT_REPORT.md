## 0. 一句话结论

RAG-ConGuard 的**联盟级归因+风险约束安全上下文选择**成立且可复现：在拒答 ≤10% 的可用性
层位上全面优于全部基线（含逐文档 LOO、TrustRAG 公平复刻之外的效用安全点）；强保护层位上
与最强的发布级防御（TrustRAG 原版）同水准但**纯证据级操作**；跨 3 个不同族 LLM 泛化方向
一致；自适应攻击变体在第 0-2 轮与**未见过的新变体族**上逃脱率均为 0。**诚实的不利面**
（均如实报告）：①代理 CCI 与生成级 exact CCI 仅**中等相关**（ρ≈0.39），论文 M6 的 JSD 形式化
必须改为"证据侧近似，分析对照"；②规则风险在部分校准点上不弱于 MLP（学习器增益有限）；
③攻击密度下"强保护"与"低拒答"存在固有代价面（58% 查询的整个上下文被联盟控制）。

## 1. 实验协议（冻结 v1.2，FINAL_PROTOCOL.md）

- 数据：NQ / HotpotQA / MS MARCO，各 600k 语料 + PoisonedRAG 基准 100 查询 × 5 篇近重复投毒
  （500 篇/数据集，~0.08%），KB 2026-08-24 构建冻结（不重建）
- 检索：BGE-base-en-v1.5（FAISS cosine）+ BM25，RRF top-5（KG 视角关闭）
- 图：NLI（nli-deberta-v3-base，th=0.7）+ 数值冲突启发式 + LLM judge α=0.3；联盟 = 正边连通分量，
  **精化 v1.2**：size≥2 且（cohesion>0 或 impact>0）——孤立单点豁免
- 影响（代理 CCI）：信任传播（refute≈2.0×4 iter）→ s_G(A)=Σp_c·max(0,sim)；候选答案 = **top-2
  查询相似 claim**（target-free，修掉旧实现的基准答案 oracle 泄漏）；I(C)=max_a Δ s/s_G(a*)
- 风险学习器：MLP(16,8)+StandardScaler（只 fit train）；**标签 = poisoned_ratio≥0.8**（修掉旧
  purity=max 标签 bug——旧实现把 all-benign 也标正），负例 = clean_trn 查询联盟
- 生成器：Qwen2.5-7B-Instruct fp16 T=0（统一 128 tok）；扩展 Llama-3.1-8B-Instruct / Mistral-7B-v0.3
- Split（冻结）：投毒 300q → train 60/val 20/test 20 每数据集（分层，共 180/60/60）；
  clean_trn 200 / clean_val 100 / clean_test 300 每数据集；全部交验无交集
- 指标：逐查询互斥主状态（attack_success/correct/refusal/other）；ASR/Acc/Refusal；
  clean 侧 refusal+良性误滤（**clean accuracy 不可得**：BEIR UKP zip 无 qas，实拉核验）
- 统计：paired bootstrap（1000 次，与 B0 成对同池）

## 2. 主结果（冻结 test，n=60，2006-08-25）

| 方法 | 选择点 | ASR | Acc | Refusal |
|---|---|---|---|---|
| B0 Vanilla | — | 0.833 | 0.100 | 0.017 |
| B1 Relevance filter | τ=0.30 | 0.833 | 0.100 | 0.017 |
| B2 Duplicate filter | τ=0.70 | 0.750 | 0.200 | 0.017 |
| **B4 NLI-consistency** | — | **0.867** | 0.083 | 0.033 |
| **B5 TrustRAG（原版复刻）** | — | **0.150** | 0.333 | **0.483** |
| B6 per-doc LOO | τ=0.50（可行） | 0.650 | 0.217 | 0.067 |
| G0 S0 | τ=0.05（强保护） | **0.217** | 0.333 | 0.400 |
| G1 S2 | λ=0.20（可行） | **0.583** | 0.300 | 0.067 |
| 检索面 | | asr@5=1.00；avg poisoned top-5 = 3.82 |

解析：
- **B4 倒挂**（0.867>0.833）：一致多数簇正是投毒簇——"多数一致性推理"在协同投毒下失效，
  是论文动机的最强反例证据
- **B5 与 G0 同层**（0.150 vs 0.217 强保护；拒答 0.483 vs 0.400）；但 B5 的"防御"= LLM 自评估
  直接改写答案（证据级入侵），G0 为证据选择——可审计性/机制归属不同，论文如实对比
- **G1 vs B6 直比（同拒答层位）**：0.583/0.300@6.7% vs 0.650/0.217@6.7%——联盟级在可用性
  层位全面领先；B2 0.750 次之
- paired bootstrap（vs B0，1000 次，test）：G1 ASR Δ=-0.250，95%CI [-0.367,-0.133]；
  G0 ASR Δ=-0.617，CI [-0.717,-0.517]。B5 ASR Δ=-0.683 CI [-0.783,-0.583]

结论：**无防御 Vanilla 在干净查询上自带 27-29% 拒答**（模型弃答基线）；防御的边际 = 拒答
+3~+3.3pp（G0）/ +2.2~2.3pp（G1），良性误滤 8.7-14.4%——utility 保留良好（协议约束：
误滤代理 ≤15% 达标；无 gold 无法给 acc，如实限制）。

## 4. Exp-1：exact CCI vs 代理（诚实核心限制）

- 实现：full 上下文 T=0 生成 H-token 探针 → full / D∖C 两条件 **teacher-force 相同前缀** →
  逐位置 JSD 平均（完全对齐，无独立解码比较）
- 结果（Spearman，代理 = impact / control 与 exact 完全一致因单调映射）：
  val H=8/16/32 → ρ = 0.360 / 0.394 / 0.386；train H=16 (n=99) → **0.393**
- 结论：**中等、稳定、H 不敏感**。代理是有效的排序信号但不是强代理 → 论文必须把 M6 表述改为
  "证据侧近似 + exact-CCI 对照分析（局限性与未来：全生成探针的成本）"；**不得**声称代理=JSD
- 分规模扰动大（n=3-16，-0.5~+0.7），报告注明样本量

## 5. Exp-2：Refusal 修复与选择器（val 60q 平面）

| 候选 | 网格 | ASR 范围 | Refusal 范围 |
|---|---|---|---|
| S0 整联盟删除 | τ 0.05-0.5 | 0.167-0.333 | **0.467-0.583** |
| S1 仅删最高风险联盟 | τ 0.05-0.5 | 0.200-0.333 | 0.467-0.533 |
| S2 贪婪重建（保留下限 λ） | λ 0.2-1.0 | 0.567-0.850 | 0.000-0.133 |
| （+ signed_semantic 图） | 同上 | 0.100-0.850 | 0.000-0.700 |

- **结构性发现**：S0/S1 拒答 47-58% 的表面灾难，本质 = 这些查询的**整个 top-5 被同一联盟
  控制**（avg 3.82/5 投毒；58% 查询 5/5 投毒），此时拒答是正确动作而非缺陷；
  S2 以保留下限换取即可用性（λ=0.2 → ASR 0.633 / refusal 0.100）
- 修完的 triple（标签 bug+单点豁免+target-free）把 val AUC 从 0.769（修复前）提到 0.858，
  训练集 0.735→0.857；τ=0.05 时投毒联盟**漏检=0**
- **诚实结论**：ASR↓70pp 且 refusal≤10% 在 76% 攻击密度下无法同时成立；
  论文操作点为：强保护点（G0 0.217@40%）+ 可用性点（G1 0.583@6.7%）

## 6. Exp-3/8：基线全集与归因机制

- 基线选点（val 约束规则）：B1 0.85（无作用、诚实保留）；B2 τ=0.7；B6 τ=0.5（唯一 ≤10% 可行）；
  B5 无参（ASR 0.20@58.3%）；B4 无参（0.85，无作用）
- **E8 归因机制（最终口径，test 39 组≥2 投毒组）**：
  组规模 2/3/4 → 单篇 LOO 0.353/0.466/0.521（慢增）vs 联盟删除 0.480/0.714/0.944（快增），
  比值 1.36x / 1.53x / **1.81x**——稀释机制成立（旧表 4 的 1.01→1.98x 为 oracle 口径，作废旧版，
  新口径下 1.36→1.81x 一致性保留）
- **规则风险消融（诚实意外）**：RuleRisk-S2 λ=0.2 = 0.533/0.350@6.7%（test）——**略优于** MLP-G1
  （0.583/0.300）→ "结构信号为主、学习器增益有限"如实写；学习器价值体现在判别 AUC（规则 0.32 系 vs
  MLP 0.79-0.86）与自动化而非端到端增益

## 8. Exp-5：跨 LLM（test 60q + clean_val，同 split 同参数）

| 模型 | B0 ASR | G0 | G1 | clean G1 ref / mis-filter |

- 三模型防御方向一致：强保护点 ASR 压至 0.25-0.30；可用性点 0.55-0.65 且拒答极低

- 干净侧：mis-filter 7.1%（Llama/Mistral）< Qwen 13.5%——防御选择与 LLM 无关地保守

## 9. Ablations 汇总

1. 标签修复（purity→poisoned_ratio + clean 负例）：训练负例 8→2843（v1.0 数字），
   refusal=100% 病态的**根因**（被 root-cause 定位并修复）
2. 单点豁免（M5 精化）：val AUC 0.769→0.858；τ=0.05 漏检归零
3. target-free 候选答案：消除推理期 oracle（旧实现用攻击答案），与 exact-CCI 口径对齐
4. graph 变体：signed vs signed_semantic（val S0: 0.183@58.3% vs 0.100@70.0%）——semantic
   双通道对纯投毒组更聚但拒答更高；主链保留 signed（低拒答面占优），semsem 记消融
5. rule vs learned：见 §6

## 11. Level 判定（诚实，按你定义的口径）

- **Level C（CCF-B 有竞争力）：未达成**。缺：代理-精确 CCI 强一致（仅 0.39）、
  MLP 端到端优势（规则持平）、跨模型面全完胜（b6/b2 在低拒答面弱于 G1 但差距不算悬殊）。
- **Level B（SCI 二区）：谨慎乐观，满足"强基线+utility+多模型+adaptive 方向性"**：
  强基线集合（含 TrustRAG 原版公平复刻）✓；clean utility ✓（误滤<15%、拒答Δ<3.3pp）；
  三模型方向一致 ✓；adaptive 逃脱 0 且 unseen 泛化 ✓。把 B4 倒挂、G0-B5 同级但机制差异、
  E8 稀释 1.36→1.81x 写成核心论证 → 有竞争力。
- **Level A（SCI 三区）：确定可投**，只要按 §10 修正论文表述 + 本报告数据。

**提升到 B 的关键动作**（已齐）：自适应 unseen 泛化（0 escape）、跨 3 模型、clean utility、
TrustRAG 对照、诚实限制段（ρ=0.39、规则持平）。**写结论时的纪律**：不宣称"代理=精确 JSD"
、不宣称"学习器全面优于规则"、不把强保护点的拒答隐藏。
