# 方案 A（最推荐，最快最省事）：默认 PyPI 的 torch 即 cu121 构建，
#       可在 CUDA 12.4 驱动上正常运行，直接走清华镜像，不碰 pytorch.org：
#   pip install torch==2.5.1 torchvision==0.20.1 -i https://pypi.tuna.tsinghua.edu.cn/simple
#
# 方案 B（严格 cu124）：用清华 pytorch-wheels 镜像（镜像了 /whl/cu124）：

#       --index-url https://mirrors.tuna.tsinghua.edu.cn/pytorch-wheels/cu124
#
# 镜像站备选：-i https://mirrors.aliyun.com/pypi/simple
