核心假设 Unsupported Influence：协同投毒不是一个「可疑文档」，而是一个证据联盟 —— 内部互相支持、外部缺乏独立佐证、却对生成结果有不成比例的控制力。本阶段完成了系统实现、实验体系审计与重建，以及全部对照实验的补齐，得到一组可信、可复现的主结果。

一本阶段完成的四项实质工作

1. 全链路系统实现（6 模块贯通）

多视角检索 → Claim 提取 → 有符号证据图 → 联盟发现 → 联盟级反事实影响 → 风险约束安全上下文选择。攻击者在环训练贯穿后三个模块。系统在 AutoDL 4090 上可复现运行，中间产物全部落盘。

2. 实验体系审计与重建（本轮最关键进展）

对既有实验做了全面审计，识别出 7 个硬伤并逐一定位根因。其中最致命的是：旧结果的低 ASR 是靠「拒答 100%」换来的，即防御在所有查询上直接弃答，等于没有防御能力。根因被定位到两个具体缺陷：

  • 标签定义错误：原用 purity = max(投毒比, 良性比) 做正例标签，导致「全良性联盟」也被标为正例（训练 409 个联盟只产生 8 个负例），学习器对一切输出高分 → 任意阈值下全部拒答。已改为 poisoned_ratio ≥ 0.8，并以干净查询联盟作为负例池。
  • 选择器无保留删除：整联盟剔除策略在 top-5 被同一联盟控制时清空全部上下文。已新增 S2 贪婪重建（保留下限 λ）。

在此基础上建立并冻结实验协议 v1.2：统一 train/val/test split、消除推理期 oracle 泄漏、逐查询互斥状态标注、paired bootstrap 统计检验。

这一项应当作为进展主动汇报

发现问题并修复，比拿到漂亮数字更能说明工作的严谨性。旧协议产物已全部作废、不可引用，当前所有结论均来自冻结协议 experiments/final_protocol/results/。

3. 强基线与对照实验补齐

  • 强基线：新增 TrustRAG 原版复刻、逐文档 LOO 防御、NLI 一致性（ReliabilityRAG 风格），与本文方法同检索器、同语料、同 split、同生成模型。
  • 干净查询效用：clean_test 900 条，测量拒答率与良性误滤率。
  • 跨大语言模型：Qwen2.5-7B / Llama-3.1-8B / Mistral-7B-v0.3。
  • 自适应攻防：3 轮攻击者在环训练 + 3 组未见变体族（held-out）。

4. 机制诊断实验 E8

验证「逐文档归因在冗余投毒下失效」这一核心动机，采用 target-free 口径（不使用攻击目标答案）。

三个必须一起讲的结论

  • 同拒答层位下联盟级优于逐文档：在拒答 6.7% 这一层，G1 (0.583) 优于逐文档 LOO (0.650)、重复过滤 (0.750)；准确率同时从 0.100 提升到 0.300。
  • B4 倒挂，反向印证问题选得对：NLI 一致性基线 ASR 0.867，反而高于无防御的 0.833。原因是「一致的多数簇」恰恰就是投毒簇 —— 多数一致性推理在协同投毒下会主动帮攻击者。这是全文动机最强的反例证据。
  • 与 TrustRAG 同级，但机制不同：B5 的 ASR 0.150 低于 G0 的 0.217，但 B5 拒答更高（48.3% vs 40.0%），且其「防御」是让 LLM 自评估后直接改写答案（证据级入侵、不可审计），G0 是纯证据选择（可审计、可追溯）。这一对照应正面呈现，不回避。

四如实说明的三条限制

1. 代理 CCI 与精确 CCI 仅中等相关（Spearman ρ ≈ 0.39）。论文原先将影响形式化为生成分布的 JSD，实现使用的是「答案支持分数」近似。已实现精确版本（teacher-forced 对齐前缀 + 逐位置 JSD），与代理的相关性在 H=8/16/32 下稳定为 0.36 / 0.39 / 0.39。结论：代理是有效的排序信号，但不是强代理，论文不得声称「CCI = JSD」，须改写为「证据侧近似 + 精确 CCI 对照分析」。

2. 规则风险在端到端指标上略优于 MLP 学习器。RuleRisk-S2 (λ=0.2) 为 0.533 / 0.350 @ 6.7% 拒答，略优于 MLP-G1 的 0.583 / 0.300。学习器的价值体现在判别能力（AUC 0.79–0.86 vs 规则的 0.32 系）与阈值自动化，而非端到端增益。这一点如实写入，不拔高。

3. 高攻击密度下「强保护」与「低拒答」不可兼得。本设置下 58% 的查询整个 top-5 被同一联盟控制，此时拒答是正确动作而非缺陷。因此论文给出两个操作点（G0 强保护 / G1 可用性），而非宣称单一最优。另：BEIR 当前快照不含 gold answer 文件，clean answer accuracy 不可得，效用只能以「良性误滤率」为代理，此限制如实标注。
